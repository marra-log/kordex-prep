# Kordex Prep — protótipo

Protótipo local para validar culling de fotos de evento **sem custo de servidor**.

## Como abrir

Abra `index.html` no Chrome ou Edge.

1. Arraste 50–500 JPGs de um evento real.
2. Espere a análise (nitidez, exposição, ruído, fotos repetidas).
3. Filtre por Manter / Revisar / Descartar.
4. Clique numa foto para ver original × enhance local.
5. Exporte o CSV para revisar.

Nada é enviado para a nuvem. Tudo roda no navegador.
